BP EPGP · UI REDESIGN SPEC · RETAIL (MIDNIGHT)

Native-Blizzard EPGP

Every window below is drawn at 1× from stock templates, atlases and GameFont objects only. Template names are the build targets; one addon asset (the round logo) is used for portraits and the minimap button. The tweaks panel lets you preview game UI scale (0.64–1.15), test mode and the GP-on-button option.

Design language

Frame chrome

  • Primary windows (Main, Auctioning, Bidding) → PortraitFrameTemplate with the logo via SetPortraitToAsset.
  • Utility windows (Award, History, Trade, compact Bidding) → DefaultPanelFlatTemplate, no portrait.
  • Close: UIPanelCloseButtonDefaultAnchors. Title: frame:SetTitle().
  • Tabs move to the bottom (PanelTabButtonTemplate), like Character and Adventure Guide.
  • All windows: SetMovable, SetClampedToScreen(true), positions saved per-character.

Backgrounds

Frame body — template NineSlice + Bg (flat dark)
Content well — InsetFrameTemplate
Column header — ColumnDisplayTemplate
Selected row — UI-QuestTitleHighlight, ADD, vertex 1,.82,0
Alternating row — white texture, alpha 0.035

Spacing grid — 4 px base

4icon-to-label, inset inner padding 8between controls; frame edge → inset 12between control groups; utility-window padding 20list row height (16 in compact) 22button / dropdown height; input 20 60top band under title on portrait frames (clears portrait)

Anchor everything with offsets from this scale. At UI scale 0.64 a 20 px row is ~13 physical px, so no hit target is smaller than 20 px tall.

Button hierarchy

Blizzard uses one red button. Show rank with size, position and count: one primary per area, bottom-right.

09

Simplify & merge

One Amount field, two buttons

EP and GP each had a field and a button. A single Amount + Reason with Award EP / Charge GP halves the inputs, and the Boss / On time / Prog presets make the most common action one click.

“Act on” replaces Action context

The target sits at the top of the panel with the selected names listed under it, so officers can see who will be awarded before they click. Clicking rows switches it to Selected automatically.

Undo instead of more confirmations

Keep StaticPopups only for raid-wide or roster-wide actions. A one-step Undo (it writes a reverting event) covers single mis-clicks without slowing every award.

Audit becomes a History filter

Audit issues are events, so the same list with “Show audit issues” and a red count in the footer is enough. That drops a tab, and Settings moves in-window as the last tab, read-only for raiders.

GP tiers prefill; the queue auto-advances

Fill the five tier fields from a slot × tier table in guild settings. After Award, the next queued item loads, so a boss's loot is Alt-click ×N → Start → Award → Start…

Winner preselected, Enter awards

When the timer ends, select the top bid (highest tier, then PR, then roll), fill its value and focus Award. The officer only steps in to override. Remove on award is on by default.

GP on the button, one row of tiers

With all five tiers in one row ordered by cost, you don't need a tooltip to see the price. Clicking a different tier replaces your bid, so Cancel is only for withdrawing.

Fold Award and Trade into existing windows

Manual award can be the right-click “Award item” on Standings (it opens the 205 px window prefilled). The trade list can be an “Untraded” filter in Auction history. That leaves fewer windows to arrange before a raid.

Timer docks by default

Show the countdown in the Bidding header (“14s left”). The separate bar is optional and draggable for people who close the window mid-auction; it reopens Bidding when clicked.
