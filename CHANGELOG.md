# BP EPGP v1.0.0 (unreleased)

## Changes
### First release
BP EPGP is a fork of Core Loot Manager v5.7.8, trimmed down to our guild's EPGP workflow on retail (Midnight).
### Coexists with Core Loot Manager
Own name, saved data, slash command (`/bpepgp`), keybindings and sync channels, so it can be installed next to CLM.
### Removed
Classic support, non-English translations, the in-game changelog window, the Tracker and Integrations add-ons, auto-roll on loot, GP prices in item tooltips, sandbox mode, time travel and cross-guild sync. The Alerts add-on is now built in.
