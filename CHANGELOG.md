# BP EPGP v1.0.0 (unreleased)

## Changes
### First release
BP EPGP is a fork of Core Loot Manager v5.7.8, trimmed down to our guild's EPGP workflow on retail (Midnight).
### Coexists with Core Loot Manager
Own name, saved data, slash command (`/bpepgp`), keybindings and sync channels, so it can be installed next to CLM.
### EPGP only
One roster with EPGP standings (PR = EP/GP), officers defined by the guild rank's "Is Officer" permission, new rosters default to Open auctions with Tiered named buttons. Use "Set up BP EPGP" in the Standings tab to create the roster.
### Removed
Classic support, non-English translations, the in-game changelog window, the Tracker and Integrations add-ons, auto-roll on loot, GP prices in item tooltips, sandbox mode, time travel, cross-guild sync, DKP, point caps, zero-sum bank, tax, dynamic item values, class multipliers, boss-kill/interval/raid-completion bonuses, bench/standby, alt-main linking, profile locking, profile pruning, attendance tracking and disenchanting. The Alerts add-on is now built in.
